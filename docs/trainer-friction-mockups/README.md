# Макеты тренажёра «Сила трения»

Одно и то же задание (брусок на доске, доску тянут вправо, брусок отстаёт) в трёх стилях.
Слева на каждой картинке — вопрос, справа — экран после ответа, где направление выбрано неверно.

- `maket-B2.png` — **выбранный вариант**: игровые карточки, разбор в светлой карточке, рядом тёмная тема.
- `maket-A.png` — строгая схема в стиле сайта (не выбран).
- `maket-B.png` — первая версия карточек: разбор в тёмном окне выбивался из страницы (не выбран).
- `maket-C.png` — тёмный «чертёж» (не выбран).

`mockups.html` — исходник макетов. Открыть в браузере с параметрами:
`?v=B&s=q` (вопрос), `?v=B&s=ans` (после ответа), `&t=dark` — тёмная тема; `v=A` и `v=C` — другие стили.
Это картинка-ориентир, а не код сайта.
