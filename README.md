# edu — тестовая страница курса

Прототип будущей образовательной платформы: страница курса со списком уроков,
видео с Rutube прямо в уроке и домашним заданием на той же странице
(подсказки по шагам, «Я не знаю», попытки, XP).

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Где редактировать контент

Всё в одном файле — `src/data/course.js`: название курса, преподаватель,
уроки, ссылка на Rutube (`videoUrl`), задачи, ответы, подсказки и решения.
Формулы пишутся в LaTeX: `$...$` и `$$...$$`.

## Правила XP (`src/lib.js`)

- Максимум за задачу — 20 XP (можно задать `xp` в самой задаче).
- Каждая подсказка снижает награду: `XP × (1 − подсказок / (всего подсказок + 1))`.
- Верный ответ со второй попытки — половина от этой суммы.
- 2 попытки на задачу. «Я не знаю» или две ошибки — задача не засчитана, 0 XP.

Прогресс хранится в `localStorage` браузера.
