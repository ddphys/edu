# edu — тестовая страница курса

Прототип будущей образовательной платформы. Две страницы:

- **Список уроков** (`#/`) — описание курса и уроки строками с прогрессом по задачам.
- **Урок** (`#/lesson/<id>`) — запись занятия с Rutube и под ней домашнее задание
  (подсказки по шагам, «Я не знаю», попытки, XP). Задачи переключаются номерами сверху.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Где редактировать контент

Всё в одном файле — `src/data/course.js`: название курса, преподаватель,
уроки, ссылка на Rutube (`videoUrl`), задачи, ответы, подсказки и решения.
Формулы пишутся в LaTeX: `$...$` и `$$...$$`.

## Правила XP (`src/lib.js`, настройки в `src/data/course.js`)

- Максимум за задачу — 20 XP (можно задать `xp` в самой задаче).
- **Попытки:** награда зависит от номера попытки по шкале `attemptMultipliers`:
  100% → 60% → 40% → 30% → 25%. Штраф с каждой ошибкой всё мягче. После 5-й ошибки задача не засчитана.
- **Подсказки:** каждая снижает награду: `XP × (1 − подсказок / (всего подсказок + 1))`.
- «Я не знаю» — задача не засчитана, 0 XP.
- Задача может иметь несколько полей ответа (`parts`): засчитывается, когда верны все.
  Верные поля фиксируются, ошибки считаются одной попыткой.

Прогресс хранится в `localStorage` браузера.
