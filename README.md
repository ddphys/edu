# edu — тестовая страница курса

Прототип будущей образовательной платформы. Две страницы:

- **Список уроков** (`#/`) — описание курса и уроки строками с прогрессом по задачам.
- **Урок** (`#/lesson/<id>`) — запись занятия и под ней домашнее задание
  (подсказки по шагам, «Я не знаю», попытки, XP).

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Где редактировать контент

Всё в одном файле — `src/data/course.js`: название курса, преподаватель,
уроки, ссылка на видео (`videoUrl`), задачи, ответы, подсказки и решения.
Формулы пишутся в LaTeX: `$...$` и `$$...$$`.

### Видео

В `videoUrl` можно вставить ссылку на YouTube, Rutube, Kinescope или прямую
ссылку на файл mp4/webm — платформа определяется сама. Сами видеофайлы в
репозитории хранить не стоит: GitHub не принимает файлы больше 100 МБ.

### Вопросы по ходу видео

Необязательное поле урока `quiz`: в указанную секунду видео встаёт на паузу
и поверх него появляется вопрос с вариантами ответа.

```js
quiz: [
  { time: 95, question: 'Текст вопроса', options: ['Вариант А', 'Вариант Б'], correct: 0, explain: 'Пояснение' },
]
```

`time` — секунда от начала видео, `correct` — номер верного варианта, считая с нуля,
`explain` — решение, оно показывается после ответа.

- XP за эти вопросы не начисляется.
- Отвеченный вопрос по ходу видео повторно не задаётся; пропущенный появится снова,
  если перемотать назад.
- Когда видео заканчивается, вопросы с ошибкой и пропущенные задаются ещё раз —
  каждый по одному разу, в конце показывается число верных ответов.
- У видео с вопросами своя кнопка «На весь экран» под плеером: разворачивается весь
  блок, поэтому вопрос виден поверх видео и из полного экрана не выбивает. Родная
  кнопка полного экрана в плеере при этом отключена. На айфоне блок растягивается
  на всё окно браузера.

### Задачи: подряд или в одной ячейке

Задачи урока идут на странице одна под другой. Несколько задач можно собрать
в одну ячейку с номерами — для коротких тестовых задач, чтобы не раздувать урок:

```js
tasks: [
  { id: 'a', /* ... */ },                                     // отдельная задача
  { title: 'Тренировка', tasks: [{ id: 'b' }, { id: 'c' }] }, // ячейка с номерами
]
```

## Правила XP (`src/lib.js`, настройки в `src/data/course.js`)

- **Цена задачи** — по уровню сложности `level` (1–5): 5 / 10 / 20 / 35 / 50 XP (`levelXp`).
  Без уровня — `defaultLevel` (2). Точное значение можно задать полем `xp` в задаче.
- **Ошибка** −20% цены, **подсказка** −25% цены (`errorPenalty`, `hintPenalty`) — вычитаются, не перемножаются.
- Если ученик решил сам, он получает не меньше 25% цены (`minShare`). «Я не знаю» — 0 XP.
- Попытки не ограничены. С 3-й ошибки после каждой неверной отправки — пауза 20 секунд
  (`cooldownFromError`, `cooldownSeconds`).
- Задача может иметь несколько полей ответа (`parts`): засчитывается, когда верны все.
  Верные поля фиксируются; одна неверная отправка — одна ошибка, сколько бы полей ни было неверно.
- Ученик видит у задачи текущую цену, цену подсказки на кнопке, а после решения — разбор
  («20 − 5 за подсказку − 4 за ошибку»). Правила кратко — по клику на XP в шапке.

Прогресс хранится в `localStorage` браузера.
