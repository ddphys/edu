# edu — образовательная платформа

Сайт курса с уроками, видео с Rutube и домашними заданиями. Есть кабинет ученика и кабинет администратора с конструктором уроков и банком задач.

- `src/` — сайт (React + Vite): страницы ученика и кабинет администратора (`src/admin/`).
- `server/` — бэкенд (Node.js + Fastify + PostgreSQL): вход, регистрация, проверка ответов, прогресс, админка.

## Запуск на своём компьютере

Нужны Node.js 22+ и PostgreSQL 14+.

```bash
npm install                 # зависимости сайта
cd server && npm install    # зависимости сервера
cp .env.example .env        # и заполните server/.env (база, email и пароль админа)
npm run seed                # создаст таблицы, перенесёт курс из src/data/course.js, создаст админа
npm run dev                 # сервер на http://localhost:3000
```

Во втором терминале, в корне проекта:

```bash
npm run dev                 # сайт на http://localhost:5173, запросы к /api идут на сервер
```

Боевой вариант: `npm run build` в корне, затем `npm start` в `server/`. Сервер сам отдаёт собранный сайт из `dist/`.

Тесты сервера (база из `TEST_DATABASE_URL` **полностью очищается**):

```bash
cd server && TEST_DATABASE_URL=postgres://postgres@localhost:5432/edu_test npm test
```

## Роли

- **Ученик** регистрируется сам на `/register` или по ссылке-приглашению `/invite/<код>`.
- **Админ** входит через ту же страницу входа, кабинет открывается по адресу `/admin`.
  Первого админа создаёт `npm run seed`. Других можно назначить в карточке пользователя.
- Роль «преподаватель» заложена в базе на будущее, но пока не используется.

## Кабинет администратора (`/admin`)

- **Конструктор курсов.** Слева дерево курсов и уроков (уроки перетаскиваются), в центре настройки урока и его задачи
  (порядок меняется перетаскиванием), справа банк задач: «+» или перетаскивание строки добавляет задачу в урок.
- **Банк задач.** Задачи с условием, полями ответа (с погрешностью), подсказками, эталонным решением, картинками,
  темой, тегами и сложностью. По каждой задаче видна статистика. Одна задача может стоять в нескольких уроках.
  Картинка вставляется в текст через Ctrl+V, перетаскиванием файла или кнопкой «Картинка».
- **Ученики.** Таблица с метками, комментариями (редактируются по клику), XP и активностью. В карточке ученика есть
  все его задачи и история попыток, смена имени и email, пароль, доступ к курсам и сброс прогресса.
  **Объединение аккаунтов:** отметьте два аккаунта галочками и нажмите «Объединить». Решения, история и доступы
  перенесутся в основной аккаунт, по каждой задаче останется лучший результат, дубль удалится.
- **Сводная по курсу.** Таблица «ученики × задачи» с цветом статуса и числом попыток.
- **Приглашения.** Ссылки с меткой. Каждый, кто зарегистрировался по ссылке, получает метку, его можно сразу
  записать на курсы. У ссылки можно задать лимит регистраций и срок действия.

## Формат текста задач

Формулы пишутся в LaTeX: `$...$` и `$$...$$`. Жирный: `**текст**`. Картинка: `![](/uploads/файл.png)`.
Пустая строка — новый абзац.

## Правила XP (`server/src/lib/tasks.js`, настройки — в курсе)

- Максимум за задачу — 20 XP (в задаче можно задать своё значение).
- **Попытки:** награда зависит от номера попытки по шкале курса: 100% → 60% → 40% → 30% → 25%. После 5-й ошибки задача не засчитана.
- **Подсказки:** каждая снижает награду: `XP × (1 − подсказок / (всего подсказок + 1))`.
- «Я не знаю» — задача не засчитана, 0 XP.
- Если в задаче несколько полей ответа, она засчитывается, когда верны все. Верные поля фиксируются, а неверные
  ответы в одной отправке считаются одной попыткой.

Ответы проверяются на сервере: правильные ответы и решения попадают в браузер только после завершения задачи.

`src/data/course.js` теперь нужен только для первого переноса курса в базу (`npm run seed`). Дальше всё редактируется в кабинете.
